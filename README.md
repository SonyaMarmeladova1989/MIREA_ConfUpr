# MIREA_ConfUpr

#Shell Emulator

## 1.Общее описание

GUI-эмулятор UNIX-подобной оболочки с виртуальной файловой системой (VFS) в памяти, загружаемой из XML.

## 2.Функции и настройки 

### Команды
- 'ls [путь]' - список файлов и каталогов
- 'cd <путь>' - переход по VFS
- 'pwd' - текущий каталог
- 'date' - текущее время
- 'clear' - очистка окна
- 'wc <файл>' -  строки / слова / символы
- 'mkdir <путь>' - создать каталог
- 'chmod <маска> <путь>' - сменить права (octal)
- 'vfs-save <путь>' - сохранить VFS в XML
- 'vfs-init' - сбросить VFS к состоянию по умолчанию
- 'exit' - выход

### Параметры командной строки
- '--vfs <path>' - путь к XML-файлу VFS
- '--script <path>' - стартовый скрипт
- '--debug' - вывести разобранную конфигурацию

### Раскрытие переменных окружение
Поддерживается '$VAR' и '${VAR}' (значения берутся из ОС)
